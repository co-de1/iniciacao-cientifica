# ECG Analysis Project

This project analyzes ECG signals using the PTB-XL dataset.

## Setup

1. Clone this repository
2. Download the PTB-XL dataset from PhysioNet
3. Place the data in `physionet.org/files/ptb-xl/`
4. Install requirements: `pip install -r requirements.txt`
